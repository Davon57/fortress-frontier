# 堡垒前线 Fortress Frontier

> 一个运行在浏览器中的实时堡垒占领策略游戏。

在《堡垒前线》中，玩家与 AI 同时扩张领地。每座堡垒持续产生士兵；从己方堡垒拖拽至目标堡垒即可派兵，击破守军后便能夺取其旗帜、驻军与产兵权。

## 核心玩法

- 实时同步：玩家与 AI 同时出兵、抢占与反攻。
- 拖拽派兵：拖拽选择目标，出兵比例由指挥台独立设定，与目标远近无关。
- 堡垒分型：兵营滚雪球、要塞卡咽喉、哨站作缓冲，先抢哪一座是有代价的选择。
- 攻守有别：守军享有堡垒防御加成，攻坚需要集结兵力，而不是随手一波。
- 战术技能：急行军、征兵令、炮火支援、坚壁各有冷却与每局次数限制。
- 占领扩张：攻破敌方或中立堡垒后，堡垒转换为己方阵营并开始产兵。
- 小人军团：行军部队会以成队的小兵显示，遭遇时按兵力比例消耗，围攻有效。
- 地形阻隔：沙丘、密林、冰湖、海峡、熔岩裂谷、山脊与城墙会实际画在战场上，只有绿洲、遗迹、山口、渡口、石桥与城门这些缺口能通行，寻路会自动取道最近的一处。
- 多样目标：除经典歼灭战外，还包含占点坚守、核心守城与连续突破任务，金色标记会指出当前战略目标。
- 敌将人格：猛攻型、守备型与扩张型 AI 会采用不同的选点、增援和出兵倾向，并携带一种可读冷却的战术技能。
- 三星挑战：每关包含胜利、限时和一项特殊条件，结算时统计用时、调令、派兵、伤亡、技能与堡垒失守。
- 三栏指挥界面：任务与挑战放在左侧，战场居中，敌情与战役进度放在右侧；桌面侧栏可折叠，窄屏自动切换为抽屉。
- 独立军团模式：保留经典玩法，另提供地面移动、远程齐射、盾墙、骑兵冲锋与三角克制的半战术战役。
- 十关战役：从边境草原一路推进到王都决战；关卡按胜利顺序解锁并保存到浏览器本地。

## 操作方式

1. 在指挥台选择出兵比例（25% / 50% / 75% / 100%），或在战场上滚动滚轮按 5% 微调。
2. 按住蓝色己方堡垒，拖向任意敌方或中立堡垒后松开。
3. 拖拽到目标堡垒上时，战场会用虚线画出部队真正会走的路线：橙色代表进攻、蓝色代表增援，金色圆点是被地形逼出来的必经节点，状态栏同时给出出兵人数、留守人数与预计抵达时间。
4. 优先争夺中央中立堡垒，建立前线并压缩敌军空间。

快捷键：`1`–`4` 切换出兵比例档位，`Q` `W` `E` `R` 施放四个战术技能，`Esc` 取消瞄准，`空格` 暂停或继续。

经典歼灭战中，一方只有在既没有堡垒、也没有在途部队时才判负，所以倾巢而出偷家仍有翻盘机会。特殊任务则可通过完成屏幕上方的目标进度直接获胜；守城关的核心堡垒一旦失守会立即失败。

## 堡垒类型

| 类型 | 产兵 | 驻军上限 | 防御 |
| --- | --- | --- | --- |
| 兵营 | 2.0 / 秒 | 60 | ×1.0 |
| 要塞 | 0.7 / 秒 | 120 | ×1.6 |
| 哨站 | 1.0 / 秒 | 45 | ×1.2 |

攻方需要打穿「守军 × 防御倍率」才能夺城，因此要塞常常需要两波才能拿下。驻军数字变成金色代表已达自然增长上限，再攒也不会变多——该出兵了。

## 战术技能

| 技能 | 快捷键 | 效果 | 冷却 / 每局次数 |
| --- | --- | --- | --- |
| 急行军 | `Q` | 10 秒内己方部队行军速度 +60% | 26 秒 / 3 次 |
| 征兵令 | `W` | 15 秒内己方堡垒产兵翻倍 | 30 秒 / 3 次 |
| 炮火支援 | `E` | 点选一支敌方行军部队，立即歼灭其 30% | 18 秒 / 3 次 |
| 坚壁 | `R` | 点选一座己方堡垒，20 秒内防御翻倍 | 24 秒 / 2 次 |

敌方指挥官只会携带一种与人格匹配的技能：猛攻型使用急行军，守备型使用坚壁，扩张型使用征兵令。第一关作为教学关不启用敌方技能。

## 战后评分

每关固定提供三个独立星级条件：完成任务可获得第一颗星，满足限时要求和本关特殊挑战可再各获得一颗。特殊挑战包括少用技能、不丢堡垒和控制己方伤亡。

胜利后会显示本局完整统计，并将最高星级、最快通关时间、最少伤亡和累计胜场保存在浏览器本地；选关按钮会直接显示每关的历史星数。

## 军团模式

在战场标题右侧切换到“军团”即可进入独立战役。每座军营只生产自己的专精兵种；异类增援会形成混编驻军，一次出兵会按兵种自动拆成多支独立编队。

- 编队既可以拖向堡垒，也可以拖向任意地面驻防；野外编队还能再次拖拽改道。
- 步兵克制骑兵，抵达地面后会组成盾墙，并为附近友军降低远程伤害。
- 骑兵克制弓兵，长距离移动会积累冲锋强度，接敌时造成突击伤害。
- 弓兵克制步兵，会在接触前停止行军并进行可见的远程齐射。
- 三个兵种拥有不同轮廓、装备、队形、移动速度和攻城效率。
- AI 会评估双方兵种构成，优先选择具有克制优势的进攻目标。
- 三关军团战役分别教学三角克制、跨河编队调度和综合会战。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址，通常是 `http://127.0.0.1:5173/`。

## 常用命令

```bash
# 生产构建
npm run build

# 运行规则测试
npm test
```

## 项目结构

```text
src/
├─ game/
│  ├─ abilities.ts    # 战术技能定义与冷却充能规则
│  ├─ ai.ts           # 敌方指挥官的进攻与增援决策
│  ├─ campaign.ts     # 关卡解锁存档
│  ├─ input.ts        # 拖拽派兵、滚轮调比例、技能瞄准
│  ├─ levels.ts       # 十关配置与战役参数
│  ├─ legion-ai.ts    # 军团 AI 的克制选点与增援决策
│  ├─ legion-app.ts   # 军团模式界面与主循环装配
│  ├─ legion-input.ts # 军团模式拖拽和比例输入
│  ├─ legion-levels.ts # 三关军团战役配置
│  ├─ legion-logic.ts # 兵种克制、生产、混编与攻城结算
│  ├─ legion-simulation.ts # 军团战局状态机
│  ├─ logic.ts        # 堡垒分型、占领、产兵、战斗等纯规则
│  ├─ navigation.ts   # 地形节点寻路
│  ├─ objectives.ts   # 歼灭、占点、守城与连续突破目标
│  ├─ renderer.ts     # PixiJS 战场绘制
│  ├─ scoring.ts      # 战局统计、挑战判定与三星结算
│  ├─ simulation.ts   # 战局状态机与每帧推进
│  └─ terrain.ts      # 地貌对产兵与战斗的影响
├─ main.ts            # 应用装配、指挥台 UI 与主循环
├─ style.css          # 战役界面基础样式
└─ layout.css         # 三栏布局、折叠侧栏与窄屏抽屉
```
