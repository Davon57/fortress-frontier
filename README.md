# 堡垒前线 Fortress Frontier

> 一个运行在浏览器中的实时堡垒占领策略游戏。

在《堡垒前线》中，玩家与 AI 同时扩张领地。每座堡垒持续产生士兵；从己方堡垒拖拽至目标堡垒即可派兵，击破守军后便能夺取其旗帜、驻军与产兵权。

## 核心玩法

- 实时同步：玩家与 AI 同时出兵、抢占与反攻。
- 拖拽派兵：拖拽距离决定本次派出的兵力比例。
- 占领扩张：攻破敌方或中立堡垒后，堡垒转换为己方阵营并开始产兵。
- 小人军团：行军部队会以成队的小兵显示，并在遭遇时实时消耗。
- 地形路线：河谷木桥、绿洲、遗迹、山口、渡口、石桥与城门会作为自动寻路节点。
- 十关战役：从边境草原一路推进到王都决战；关卡按胜利顺序解锁并保存到浏览器本地。

## 操作方式

1. 按住蓝色己方堡垒。
2. 拖向任意敌方或中立堡垒。
3. 拖得越远，派出的兵力比例越高。
4. 优先争夺中央中立堡垒，建立前线并压缩敌军空间。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址，通常是 `http://127.0.0.1:5173/`。

## 常用命令

```bash
# 生产构建
npm run build

# 运行规则测试
npm test
```

## 项目结构

```text
src/
├─ game/
│  ├─ levels.ts       # 十关配置与战役参数
│  ├─ logic.ts        # 占领、产兵、战斗等纯规则
│  └─ logic.test.ts   # 核心规则测试
├─ main.ts            # 战场渲染、输入、AI 与行军循环
└─ style.css          # 战役界面样式
```
